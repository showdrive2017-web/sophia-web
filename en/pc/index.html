Unlock the PC version

  1. Buy on your phone. Make the one-time purchase from the app’s purchase screen.
  2. Find your code. After buying, a code like SOPH-XXXX-XXXX-XXXX appears on the phone’s purchase screen (open it from Star list → Settings).
  3. Enter it on PC. In the PC version, go to Projects → “Trial · Unlock full version” and enter the code.

Opening a project file exported from a phone that has bought SOPHIA (“Open from file”) also unlocks the PC version automatically.

How to install

  1. Open the downloaded SOPHIA-setup.exe.
  2. If you see “Windows protected your PC”, press “More info”, then “Run anyway”. SOPHIA is still new and has few downloads, so Windows shows this check. If the publisher reads “草苅佳宣” (Yoshinori Kusakari), it is the official SOPHIA file. Security software such as Norton may scan the file for about 20 seconds the first time; when it says it looks safe, you can use it as usual.
  3. Follow the steps on screen, and SOPHIA’s icon appears on your desktop and in the Start menu.
